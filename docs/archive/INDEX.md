# Historical records — recommendations withdrawn

These files preserve the documentation that preceded the classical reset,
including uncommitted GLS work. Their production claims and recommendations
are withdrawn. They are not documentation of the new classical API.

- README.md: previous rationale and APIs
- WORKFLOW.md: previous workflow
- TABLES.md: legacy output columns
- FINDINGS.md: previous experiments and interpretations

The corresponding classical code is in `diffusionkit.legacy.classic`.
The old public import paths forward to it for compatibility. Bayesian and
anisotropy source code has not yet been revised.
